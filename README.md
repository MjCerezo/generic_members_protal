# Acacia Membership Web

A premium Nuxt.js 3+ frontend for the Acacia Membership Application system.

## 🎨 Design System
- **Theme**: Premium Light Aesthetic
- **Framework**: Nuxt 3, Tailwind CSS
- **Icons**: Lucide Vue Next

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
cd acacia-membership-web
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```

## 📂 Project Structure
- `app.vue`: Main layout wrapper.
- `pages/index.vue`: Terms & Conditions / User Responsibility Agreement.
- `pages/membership.vue`: Multi-step Membership Application Form.
- `assets/css/main.css`: Core design tokens and premium utility classes.
- `composables/`: Reusable logic for API and state.
